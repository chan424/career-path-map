# Career Path Map

Interactive tool for visualizing and exploring career pathways based on skills, education, and interests.

## Overview
Helps students (especially engineering and science undergraduates) and professionals map possible career trajectories. Inspired by career path holder databases and skill-based roadmaps.

## Features
- Interactive graph/network visualization of career paths
- Skill-to-role mapping
- Education and experience filters
- Personalized path recommendations
- Export or share career plans
- Support for domains like Software, Data Science, Environmental Engineering, etc.

## Tech Stack
- **Frontend**: JavaScript / React + D3.js or Cytoscape.js for graphs
- **Data**: JSON skill/career taxonomy
- **Backend** (optional): Node.js or Python for dynamic recommendations

## Use Cases
- RGUKT students planning post-graduation paths
- Career counselors
- Self-exploration of tech and research careers

## Getting Started
1. Clone the repo
2. Open `index.html` or run the local development server
3. Explore the interactive map

## Data Model
Careers, skills, and transitions stored in structured JSON for easy extension.
